# 너궁그매 스캐너 — 전체 로드맵

> 마지막 업데이트: 2026-11-22
> 새 작업은 이 로드맵에서 하나를 골라 **채팅 1개 = 작업 1개**로 시작한다. 끝나면 체크하고, 결정 내용은 해당 현황 문서에 반영한다.

## 가장 중요한 것 (모든 단계의 기준)
타깃이 이 앱에서 원하는 건 세 가지다. 화면·디자인·결제는 모두 이 셋을 잘 전달하기 위한 수단이다.
1. **논리적인 MBTI 추측** — "왜 그 유형인지" 실제 말풍선 근거로 납득된다
2. **공감되는 설명** — "맞아, 이 사람 진짜 이래"라는 느낌이 든다
3. **고민·궁금증을 풀어주는 조언** — 읽고 나서 무엇을 할지(무슨 말을 보낼지) 알게 된다

## 웹앱 설계 순서: 화면 흐름 → 디자인 → 콘텐츠 질 → 결제

### W1. 화면 흐름 — "어떤 화면이, 어떤 순서로, 무엇을 담는가"
결과물: 화면 목록 + 화면별 구성 요소 + 이동 흐름도 (와이어프레임 수준, 색·꾸밈 없이)
- [ ] W1-1 전체 사용자 흐름: 홈 → 무료 / 심층 / 관계 해석 각각의 길, 무료 → 유료로 넘어가는 지점, 결제 실패·재시도, 다시 보기
- [ ] W1-2 입력 화면 구성: 캡처 업로드, 관계, 행동 문항, 메모, 내 MBTI·궁금한 상황 — 단계 수와 순서, 건너뛰기 가능 여부
- [ ] W1-3 **결과 화면 구성(무료·심층·관계 해석)**: 위 "가장 중요한 것" 3가지가 각각 어느 블록에, 어떤 순서로 보이는지. 무료에서 무엇을 보여주고 무엇을 잠그는지
- [ ] W1-4 기타 화면: 로딩(분석 중), 보관함, 오류·데이터 부족 안내
> 현재: 디자인 시안 캔버스에 6개 화면 초안이 있음 → W1에서 흐름을 먼저 확정하고 시안을 거기에 맞춰 정리

### W2. 디자인 — "확정된 흐름에 옷 입히기"
결과물: 디자인 규칙(색·글꼴·버튼·카드·말풍선) + 화면별 확정 시안
- [ ] W2-1 디자인 규칙 정리 (노랑 = 카톡·무료, 보라 = 유료, 흰/노란 말풍선 규칙)
- [ ] W2-2 홈 (모바일·데스크톱)
- [ ] W2-3 입력 화면들
- [ ] W2-4 결과 화면 3종 + 로딩·보관함
> 현재: 시안 v3 있음 (https://claude.ai/artifact/T88q6Rnqm3sfCfcAudufvV)

### W3. 콘텐츠 질 — "가장 중요한 단계"
결과물: 분석 엔진 + 결과 문장 품질 기준 + 검증된 결과 예시
- [ ] W3-1 유료 모델 결정 (Claude Sonnet 5.5 vs GPT-6.1 Sol 비교 테스트)
- [ ] W3-2 **논리적 추측**: 지침서 v2 판단 규칙 점검, 추출 단계 경량화(옮겨 적기 전용), 여러 회사 모델 연결
- [ ] W3-3 **공감되는 설명**: 결과 문장 작성 규칙 — 인용 연결, 바넘 문장 금지, 이 사람에게만 맞는 묘사. 결과 블록별 좋은 예/나쁜 예 만들기
- [ ] W3-4 **고민 해결 조언**: 관계 해석 프롬프트 — 내 의도 vs 상대 해석, 속마음 + 다른 가능성, 해결 방법, **내 말투로 쓴 보낼 문장**, 피할 말
- [ ] W3-5 품질 검증: 실제 MBTI를 아는 카톡 정답 세트 20~30개, 채점 기준표(정확성·근거·공감·실용성·문장력), 버전별 점수 비교
- [ ] W3-6 행동 문항 개편 (지금 문항은 말투 위주라 근거가 약함)
> 현재: 지침서 v2 + 단계별 분석 → PR #2 (미병합)

### W4. 결제 — "가치를 느낀 순간에 자연스럽게"
결과물: 3단 상품 결제 + 업그레이드 흐름
- [ ] W4-1 상품 3종: 무료(기기당 3회) / 심층 1,900원 / 관계 해석 4,900원
- [ ] W4-2 차액 결제 (심층 → 관계 해석 3,000원)
- [ ] W4-3 보관함·다시 보기 (산 리포트는 재열람 무료)
- [ ] W4-4 이용권 기기 귀속 문제 → 로그인 도입 여부 결정
- [ ] W4-5 결제 실패·환불 안내

### W5. 출시 준비
- [ ] 실제 캡처로 전체 흐름 테스트 (모바일 위주)
- [ ] 개인정보 안내(캡처 원본 미저장), 이용약관, 재미·참고용 고지
- [ ] 결과 피드백 버튼("맞았어요/아니에요")으로 품질 데이터 쌓기
