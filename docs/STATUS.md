# 너궁그매 스캐너 — 웹앱 현황

> 마지막 업데이트: 2026-11-22 (오후)
> 새 대화를 시작할 때 이 문서를 기준으로 삼고, 작업이 끝나면 "다음 할 일"과 "결정 기록"을 갱신한다. 날짜별 흐름은 `04_작업기록.md`.

## 한 줄 소개
카톡 캡처를 올리면 그 사람의 MBTI를 추정하고, 말투 속 속마음과 나에게 맞는 다가가는 법까지 알려주는 웹앱.

## 타깃과 핵심 가치
- 타깃: MBTI에 관심 있고 썸·연애 중인 20~30대(40대까지) 여성. "그 사람 왜 저렇게 답장하지?", "이 말 무슨 뜻이지?" 하는 순간이 있는 사람
- 핵심 가치 3가지: ① 논리적인 MBTI 추측 ② 공감되는 설명 ③ 고민·궁금증을 풀어주는 조언

## 만드는 방식: rev.5 = 화면은 새로, 뒷단은 재사용
- `rev.4`에서 `rev.5` 브랜치를 따서 **프론트(화면)는 새 시안대로 새로 만든다**
- **결제·DB·분석 엔진·Vercel 배포 설정은 rev.4 것을 그대로 쓰고**, 새 요금제에 맞게만 손본다
- 이유: 옛 화면과 새 화면을 한 줄씩 맞추는 통합은 복잡함. 결제는 다시 만들면 검증 비용이 큼

## 디자인 (시안 있음, 코드 미적용)

  - ⓪ 홈 데스크톱, ① 홈 모바일, ② 캡처 업로드, ③ 내 MBTI·궁금한 상황, ④ 무료 결과, ⑤ 심층 리포트, ⑥ 관계 해석
- 시안 파일: **PNG 7장 = 프로젝트 파일**, **HTML·PNG = GitHub `docs/design/` (PR #3)** — 구현은 HTML 기준
- 홈 구성: 히어로 → 관계 띠 → 이용 방법 3단계 → "뭐라고 보내면 좋을까?" 샘플 → 가격 3칸 → FAQ
- 색: **노랑 = 카톡·무료**, **보라 = 유료**, 바탕 아이보리
- 결과 화면 핵심: "이 말에서 이걸 봤어요"(실제 말풍선 인용 + 단서 태그)
- **아직 시안에 없는 것**: 하단 사업자 정보 블록, 약관·개인정보·환불정책 페이지 (PG 심사 필수)

## 결제·PG 심사 준비
- 예전 PG 신청이 반려된 이유: 완성된 웹앱이 없었고, 화면 하단 사업자 정보가 없었음
- **카드사 심사 때 사이트에 있어야 하는 것**
  - 하단: 상호(엘크리컴퍼니, 사업자등록증과 일치), 대표자, 사업장 주소, 사업자등록번호, 고객센터 연락처·이메일, **통신판매업 신고번호**(없으면 국민카드 제외)
  - 화면 가격 = 실제 결제 금액, 바로 구매 가능한 상품 1개 이상
  - 환불정책 게시, 이용약관, 개인정보처리방침
- 신청 시점: **rev.5가 실제 주소에 올라간 뒤** (심사자가 사이트를 직접 봄). 신청~실결제 통상 3주
- 포트원 값 3개(Vercel 환경변수): `NEXT_PUBLIC_PORTONE_STORE_ID`, `NEXT_PUBLIC_PORTONE_CHANNEL_KEY`, `PORTONE_API_SECRET`. 실결제 전환 시 채널 키만 실채널 키로 교체
- 주의: 사주·운세는 PG 유의업종 → MBTI만으로 먼저 심사 통과 후 사주는 나중에
