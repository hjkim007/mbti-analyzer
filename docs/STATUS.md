# 너궁그매 스캐너 — 웹앱 현황

> 마지막 업데이트: 2026-11-22
> 새 대화를 시작할 때 이 문서를 기준으로 삼고, 작업이 끝나면 "다음 할 일"과 "결정 기록"을 갱신한다.

## 한 줄 소개
카톡 캡처를 올리면 그 사람의 MBTI를 추정하고, 말투 속 속마음과 나에게 맞는 다가가는 법까지 알려주는 웹앱.

## 타깃과 핵심 가치
- 타깃: MBTI에 관심 있고 썸·연애 중인 20~30대(40대까지) 여성. "그 사람 왜 저렇게 답장하지?", "이 말 무슨 뜻이지?" 하는 순간이 있는 사람
- 핵심 가치 3가지: ① 논리적인 MBTI 추측 ② 공감되는 설명 ③ 고민·궁금증을 풀어주는 조언

## 기술 구성
- Next.js 15 + Tailwind, Supabase(분석 기록·무료 횟수·결제), 포트원 결제, Vercel 배포
- 저장소: GitHub `hjkim007/mbti-analyzer` (기본 브랜치 `rev.4`)
- 로그인 없음 — 기기 ID로 무료 횟수 관리
- 기존 설계 문서(bkit PDCA): `docs/01-plan/features/mbti-analyzer.plan.md`, `docs/02-design/features/mbti-analyzer.design.md`, `.bkit/reports/mbti-analyzer-final-report.md`, `docs/overall_guide.md` — 일부 내용이 옛 결정 기준(가격 2단, 가중치 50/15/35, 글래스모피즘 등)이라 v2로 갱신 필요

## 배포 계획: 두 번에 나눠 내보낸다

| | **v1 (먼저 배포)** | **v1.1 (이어서)** |
|---|---|---|
| 디자인 | 새 시안 적용: 홈, 업로드·입력, 무료·심층 결과, 로딩 | 관계 해석 입력·결과 화면, 보관함 |
| 분석 | 분석 엔진 v2(PR #2) + 유료 모델 결정 | 관계 해석 프롬프트(내 말투로 쓴 보낼 문장) |
| 결제 | **기존 결제 그대로**(무료 3회 + 심층 1,900원) | 3단 가격(관계 해석 4,900원), 차액 결제, 보관함·재열람 |

- 이유: v1은 이미 있는 기능에 새 디자인과 더 좋은 분석을 입히는 것이라 위험이 적고 빨리 나감. 결제 구조 변경은 손이 많이 가고 돈 문제라 따로 뗀다.

## 서비스 구조 (최종 목표)

| 단계 | 가격 | 입력 | 결과 |
|---|---|---|---|
| 무료 빠른 추정 | 0원, 기기당 3회 | 캡처 최대 3장 | 유력 유형·후보, 캡처 단서 2~3개, 소통 팁 1개, 유료 미리보기(잠금) |
| 심층 리포트 | 1,900원 | 캡처 최대 10장 + 관계 + 행동 7문항 + 메모 | 지표별 찬성·반대 근거, 관계 상황별 성향, 소통 가이드, 한계 |
| 관계 해석 (v1.1) | 4,900원 (심층 구매자는 차액 3,000원) | 심층 입력 + 내 MBTI + 관계 목표 + 궁금한 상황 최대 2개 | 심층 전부 + 궁합 + 상황별 속마음·다른 가능성 + 해결 방법 + 바로 보낼 카톡 문장 + 피할 말 |

## 디자인 (시안 있음, 코드 미적용)
- 시안 캔버스: claude.ai 아티팩트 "너궁그매 스캐너 · 디자인 시안" (https://claude.ai/artifact/T88q6Rnqm3sfCfcAudufvV)
  - ⓪ 홈 데스크톱, ① 홈 모바일, ② 캡처 업로드, ③ 내 MBTI·궁금한 상황, ④ 무료 결과, ⑤ 심층 리포트, ⑥ 관계 해석
- 홈 구성: 마인드픽 체험홈과 같은 순서 — 히어로 → 관계 띠 → 이용 방법 3단계 → "뭐라고 보내면 좋을까?" 샘플 → 가격 3칸 → FAQ
- 색: **노랑 = 카톡·무료**(메인 CTA "카톡 캡처로 무료 분석하기", 무료 배지, 내가 보낼 말풍선), **보라 = 유료**. 바탕 아이보리
- 결과 화면 핵심: "이 말에서 이걸 봤어요"(실제 말풍선 인용 + 단서 태그)
- 참고: 마인드픽 체험홈 https://mindpick-juna-lab.gardenrat7.chatgpt.site/ (ChatGPT 로그인 필요)
