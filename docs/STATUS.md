# 너궁그매 스캐너 — 웹앱 현황

> 마지막 업데이트: 2026-11-22
> 새 대화를 시작할 때 이 문서를 기준으로 삼고, 작업이 끝나면 아래 "다음 할 일"과 "결정 기록"을 갱신한다.

## 한 줄 소개
카톡 캡처를 올리면 그 사람의 MBTI를 추정하고, 말투 속 속마음과 나에게 맞는 다가가는 법까지 알려주는 웹앱.

## 기술 구성
- Next.js 15 + Tailwind, Supabase(분석 기록·무료 횟수·결제), 포트원 결제, Vercel 배포
- 저장소: GitHub `hjkim007/mbti-analyzer` (기본 브랜치 `rev.4`)
- 로그인 없음 — 기기 ID로 무료 횟수 관리

## 서비스 구조 (확정)

| 단계 | 가격 | 입력 | 결과 |
|---|---|---|---|
| 무료 빠른 추정 | 0원, 기기당 3회 | 캡처 최대 3장 | 유력 유형·후보, 캡처 단서 2~3개, 소통 팁 1개 |
| 심층 리포트 | 1,900원 | 캡처 최대 10장 + 관계 + 행동 7문항 + 메모 | 지표별 찬성·반대 근거, 관계 상황별 성향, 소통 가이드, 한계 |
| 관계 해석 (신규) | 4,900원 (심층 구매자는 차액 3,000원) | 심층 입력 + **내 MBTI + 관계 목표 + 궁금한 상황 최대 2개** | 심층 전부 + 궁합 + 상황별 속마음 해석·다른 가능성 + 해결 방법 + 바로 보낼 카톡 문장 + 피할 말 |

## 디자인 (시안 확정, 코드 미적용)
- 시안 캔버스: claude.ai 아티팩트 "너궁그매 스캐너 · 디자인 시안" (https://claude.ai/artifact/T88q6Rnqm3sfCfcAudufvV)
  - ⓪ 홈 데스크톱, ① 홈 모바일, ② 캡처 업로드, ③ 내 MBTI·궁금한 상황, ④ 무료 결과, ⑤ 심층 리포트, ⑥ 관계 해석
- 원칙: 마인드픽 체험홈의 구성(히어로 → 관계 띠 → 이용 방법 3단계 → 샘플 → 가격 3칸 → FAQ)과 톤(아이보리·보라)을 차용, 카톡 느낌은 대화가 나오는 자리에만
- 색: **노랑 = 카톡·무료**, **보라 = 유료**. 상대 말 = 흰 말풍선, 내가 보낼 말 = 노란 말풍선
- 결과 화면의 핵심: "이 말에서 이걸 봤어요"(실제 말풍선 인용 + 단서 태그)

## 분석 엔진 v2 (PR #2, 미병합)
- PR: https://github.com/hjkim007/mbti-analyzer/pull/2 (브랜치 `feat/analysis-pipeline-v2`)

- 단계별 분석: 유료 = 단서 추출 → 판단 → 작성 / 무료 = 추출 → 판단·작성
- 판단 결과로 최종 리포트의 유형·축·후보·확신도를 덮어써 일관성 보장
